# Difficulty-Based Study Planner using Python

## 📌 Overview
This is a simple and user-friendly study planner application that helps students create a balanced study timetable. Subjects are assigned difficulty levels, and the system automatically distributes total study hours based on these difficulty ratings. Harder subjects receive more time, promoting an efficient study pattern.

## ⭐ Features
- Add and manage subjects easily
- Assign difficulty levels (1 to 5)
- Automatic study hours allocation based on difficulty
- Generate a timetable for multiple days
- Display the schedule in a readable format

## 🛠️ Technologies Used
- Python (Core + OOP Concepts)
- Command-line interface (CLI)
