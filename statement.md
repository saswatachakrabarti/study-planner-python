## 🔹 Problem Statement
Students often struggle to divide their study time properly among different subjects. Without a structured plan, difficult subjects may receive less attention. A system is needed to help distribute time more effectively.

## 🎯 Scope of the Project
This system helps students create a timetable based on subject difficulty, using weighted distribution. It allows adding subjects, viewing them, and generating a timetable for a number of days. Data exists only during program run, making it simple and lightweight.

## 👥 Target Users
- Students preparing for exams
- College and school learners
- Anyone studying multiple subjects

## ✨ High-Level Features
- Add subjects with difficulty rating
- View all subjects
- Generate weighted study timetable
- Display result clearly in console
